## [1.2.0] — 2026-09-11

### Added

- Тестовый режим заново: профиль целиком или отдельные параметры (qdisc, алгоритм, буферы, `tcp_notsent_lowat`, `tcp_slow_start_after_idle`, `tcp_mtu_probing`) включаются только на время теста, замер A → B.
- Замер на сервере соединения тестирующего: скорость в обе стороны, RTT без нагрузки и под нагрузкой, ретрансмиссии, проверка алгоритма; клиент определяется по IP автоматически.
- Необязательный ввод цифр с клиентского теста, таблица A/B с выводом, история тестов.
- Автоматический откат временных значений при Ctrl+C, обрыве SSH и любом выходе.
- После применения показывается точная команда перезапуска ядра, в том числе для remnanode (s6 внутри контейнера).

### Changed

- Все подменю оформлены в стиле главного меню: общая шапка, разделы, эмодзи, единая строка выбора; бэкапы выбираются по номеру.
- Таблицы с кириллицей выравниваются по символам, а не по байтам.

### Fixed

- «Проверить обновления»: после обновления меню перезапускается на новой версии (раньше в памяти оставалась старая копия, и обновление предлагалось снова); обход кеша GitHub, проверка скачанного файла, корректное сравнение версий.
- Вопросы в swap, лимитах и откате из бэкапа не отображались, а текст подсказки попадал в ответ.

## [1.1.0] — 2026-09-11

### Changed

- Главное меню переработано: пункты сгруппированы по разделам (Оптимизация / Сервер / Проверка / Обслуживание), понятные названия, эмодзи и подсказки.
- В шапке меню — статус оптимизации, объём RAM, текущие алгоритм и qdisc, сетевой интерфейс.
- Новая нумерация: применить оптимизацию — пункт 1, текущее состояние — 7, диагностика — 8, бэкапы — 10.
- Подменю (тестовый режим, диагностика, бэкапы, замеры) оформлены в том же стиле.
- Отдельные картинки меню для английского и русского README.

## [1.0.0] — 2026-09-09

### Added

- Автоопределение профиля по объёму RAM: `1g`, `2g`, `4g`, `8g`; ручное переопределение через меню и `--profile`.
- Запись параметров в `/etc/sysctl.conf` управляемым блоком между маркерами; повторный запуск заменяет блок целиком.
- Автоматическое комментирование дублей тех же ключей выше по файлу.
- Превью «сейчас → станет» перед записью и бэкап `/etc/sysctl.conf` с ротацией (10 последних).
- Автоматическое удаление ключей, которые ядро не приняло (`cannot stat`, `Invalid argument`, контейнеры без прав).
- Проверка доступности BBR с предложением `cubic` как запасного варианта.
- Навешивание qdisc на дефолтный интерфейс через `tc qdisc replace` — без перезагрузки.
- Ручной режим: пошаговый проход по параметрам с объяснениями, сохранение выбора в `/etc/vpn-node-tuner/params.conf`.
- A/B-эксперименты на лету (`sysctl -w`) без записи в файл: `fq`/`fq_codel`, `bbr`/`cubic`, `tcp_notsent_lowat`, `tcp_mtu_probing`, плюс закрепление удачной комбинации.
- Настройка swap: `fallocate` с запасным `dd`, подключение и запись в `/etc/fstab`.
- Лимиты файловых дескрипторов: systemd-override `LimitNOFILE`, блок в `limits.conf`, проверка фактического лимита из `/proc/PID/limits`, подсказка `ulimits` для Docker.
- Диагностика: конфликты в `/etc/sysctl.d/`, слипшиеся строки, живые сокеты (`ss -tin`), TCP-буферы и следы OOM-killer.
- Снимки состояния ядра (baseline) и сравнение «до / после».
- Бэкапы и откат: восстановление из любого бэкапа, удаление только своего блока.
- Двуязычный интерфейс (русский / английский) с выбором при первом запуске.
- Неинтерактивный режим: `--yes`, `--profile`, `--lang`, `--size`, `--service`.
- Установка как команда `vpntune`, самообновление через `vpntune update`.
